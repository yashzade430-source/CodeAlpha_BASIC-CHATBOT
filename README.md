# CodeAlpha_BASIC-CHATBOT

Project Name: BASIC CHATBOT

This is a simple rule-based chatbot developed using Python. The chatbot takes user input and responds with predefined messages. It uses conditional statements to identify user queries and provide appropriate responses.

Features:
1] Responds to "hello"
2] Responds to "how are you"
3] Responds to "bye"
4] Runs continuously until the user exits

Concepts Used:
- Functions
- While Loop
- If-Elif-Else Statements
 - Input/Output Operations

Working:
1. The chatbot starts and waits for user input.
2. It compares the input with predefined commands.
3. If a match is found, it displays the corresponding response.
4. If the user enters "bye", the chatbot ends the conversation.
5. For unknown inputs, it displays a default message.
